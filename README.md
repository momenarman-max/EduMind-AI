# EduMind AI

لوحة للمعلّم تتابع قياسات الرياضيات والحضور وتبني خطة دعم قابلة للتعديل لمدة ثمانية أسابيع. يدعم المشروع سجلات طلاب متعددة بالعربية والإنجليزية والأوكرانية.

## جرّب المشروع

- [اللوحة](index.html) تعمل من المتصفح ببيانات تجريبية أو بقياسات تُدخل يدويًا.
- [مخطط n8n التفاعلي](n8n-flow.html) يشرح المدخلات والمخرجات عند كل عقدة.
- [ملف المسار للاستيراد](n8n/detection.workflow.json) يحتوي على عقد n8n الفعلية.

## شغّل n8n واللوحة

شغّل `node n8n/start-local.cjs` بعد تثبيت n8n حسب [دليل التشغيل](n8n/README.md). اللوحة على المنفذ 8080 ومحرّر n8n على 5678. يربط خادم Node اللوحة بمسار n8n، ويحفظ مفتاحه خارج المتصفح.

## أنشئ نسخة للاستضافة الثابتة

شغّل `node build-site.cjs` وانشر محتويات `dist` على الاستضافة الثابتة. تعمل هذه النسخة بقواعد الوكلاء داخل المتصفح وتخزّن الإدخالات في المتصفح نفسه.

لتشغيل n8n وGoogle Sheets وOpenAI من موقع مستضاف، يلزم خادم قادر على تشغيل Node وn8n وضبط اعتمادات الخدمات لديه. المسار المحلي الحالي يربط الخدمات عبر إعدادات الخادم المذكورة في دليل التشغيل.
